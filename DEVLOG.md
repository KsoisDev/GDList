# Basement List — Development Log

Development updates are kept in GitHub for the project team. Planned items below are ideas, not released features.

## 25 August 2026 — Major website revamp

### Added

- A consistent Basement design across the homepage, lists, rankings, submissions, and profiles.
- Separate main and community rankings, plus profile progress views.
- A persistent language selector for English, French, Russian, and Spanish.
- Sign-in, registration, password reset, email verification, and return-to-page account flows.
- Clear Admin, Owner, and List Dev badges, with developer credit for ntyu2 and Ksois.

### Improved

- Mobile layouts for navigation, tables, forms, profiles, and list pages.
- Shared read caching, faster searching, and a saved main-list fallback when Firebase is unavailable.
- Keyboard controls, labels, focus states, reduced-motion support, and accessible feedback.

### Fixed

- GitHub Pages routing, repository base paths, refresh handling, and deployment.
- Leaderboard points, community completion totals, list ordering, and the mobile Manage Users table.
- Safer submission reviews, scoped notifications, suspended-account guards, and clearer Firebase errors.

### In progress

- Hardening admin workflows and production data rules without replacing existing player or list data.
- Reviewing community feedback and polishing translations across management screens.

### Planned — not yet released

- Achievements and profile milestones.
- A random uncompleted-level button.
- Richer leaderboard statistics and community-level browsing filters.

Created by **ntyu2** and **Ksois**.
